## What's included

IgnisCore is the runtime framework: extension loading, block and item registries, resource-pack generation, and a layered plugin API. **Extension content** (blocks, items, textures) is built separately — see [IgnisCore-Extensions](https://github.com/%%site.extensionsRepo%%) for reference implementations.

## Install in 5 steps

1. Download **`%%site.jarName%%`** from [GitHub Releases](https://github.com/%%site.repo%%/releases).
2. Install **NBTAPI** on Bukkit-family servers (required dependency).
3. Copy the jar into `plugins/` and restart the server.
4. Deploy extension JARs to `plugins/IgnisCore/blocks/` and `plugins/IgnisCore/items/`.
5. Run `/ignis reload all` — then `/ignis` for the help menu.

See [Requirements](/requirements) for Java, platform, and dependency details.

## Your first extension

After deploying extensions and reloading:

```text
/ignis give <player> block nuke
/ignis give <player> item grenade
```

Reload after dropping new extension JARs into the plugin data folder:

```text
/ignis reload all
```
